# Native coverage and comparison scope

The same sixteen named cards, fixtures, local actions, explicit 4→2→1 columns and reset boundaries appear in every page. This is a task-equivalent composition, not a claim of identical component inventories or cost.

## Source choices

- [Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started): the styled package and its default Theme. No hand-painted imitation of Radix Primitives.
- [Fluent 2](https://fluent2.microsoft.design/get-started/develop): React v9/Griffel and Web Components v3/FAST as distinct projects. Both use `webLightTheme`; the marketing site's rose/neutral editorial skin is not imposed on product controls.
- [React Spectrum S2](https://react-spectrum.adobe.com/getting-started): S2 Provider, native controls and build-time style macros. [Spectrum Web Components](https://github.com/adobe/spectrum-web-components/tree/main/gen2): individual `@adobe/spectrum-wc` 2.0.0-beta.3 registrations, shipped Gen2 light/medium styles and retained 1.12.2 Spectrum Two form/dialog/menu controls where Gen2 has no equivalent. [Coverage and build details](spectrum-web-components/README.md). This mixed-generation implementation is not React S2; historical timing/DOM tables still describe the frozen Gen1 build.
- [Astryx](https://github.com/facebook/astryx/tree/413fa55281d1565abae8319e9803c8ccc639bc28): the published core/Neutral 0.6.2 consumer setup, including precompiled StyleX CSS. No unnecessary Babel StyleX transform is added to already compiled packages. The branded docs theme that inspired En Reve is not the native default.
- [shadcn/ui](https://ui.shadcn.com/docs/installation/vite): official `base-rhea` registry source, neutral colors, Geist, Lucide and Tailwind. The registry response URLs and SHA-256s are retained in `shadcn-react/registry-provenance.json`. Installation transformations resolve `cn`, local imports and the registry's `IconPlaceholder` to Lucide. A small `thumbLabel` prop makes the generated slider's real thumb accessible. Upstream license is retained. Source-owned components are normal shadcn delivery, not an installed lookalike package.
- [Web Awesome](https://webawesome.com/docs): free `@awesome.me/webawesome` 3.13.0, direct component imports from its bundler-oriented `dist` distribution and shipped Default light theme. The separately named Awesome theme and Pro-only components are outside this fixture.
- En Reve: real current built packages in tarballs, copied showcase template/actions, default light tokens compiled before delivery. See `en-reve/snapshot.json`.

## Native controls

All projects use native library buttons, inputs/textareas, checkboxes, switches, selection controls, tabs, progress, sliders, badges, avatars, modal dialogs and command menus. Form-control labels, controlled values and change handlers use the source APIs. Providers and default CSS are retained. The three external WC implementations use native DOM events and individual element registration. No all-components registration bundle is used.

The fixtures do not copy one library's control CSS onto another. Application layout uses normal CSS, and each library remains responsible for its internal rendering, style installation, overlay mechanics, keyboard behavior and focus restoration. Radix Themes' slider thumb receives its accessible name through its root ref because the Theme component forwards ARIA props to the root rather than the thumb; the source component is otherwise intact.

## Later profiling

Use the unflagged production origins. Record browser, viewport, device scale, input modality, cache/font state, motion settings and these pinned build identities. Compare shared workflows and native matched families separately from fallback cases. All fixtures are client-rendered, so the results will not characterize the documentation site's SSR/hydration. Exact typography, control density, native pickers, stylesheet packaging and per-library component inventories remain independent variables.

The browser harness uses Fluent custom-element selectors where Playwright's role locator does not observe roles stored in ElementInternals. It does not replace Fluent's native semantics. Astryx BottomSheet remains modal through its exit animation; tests wait for the actual `:modal` to close before entering another field. Neither accommodation changes the library runtime.

## Web Awesome addition

The free package uses `wa-input type="date"` with the browser date picker. Web Awesome’s separate custom Date Input/Date Picker and searchable Combobox are Pro components and are not installed. People selection uses free `wa-select` with the same participant choices; selection/invitation is covered, searchable filtering is not a matched capability. The activity selector uses horizontal button-style `wa-radio-group`; disclosure uses `wa-details`. Navigation links remain application-authored semantic HTML; breadcrumbs use native `wa-breadcrumb` and `wa-breadcrumb-item`. Native component behavior, internal rendering and styling are preserved; any qualification limitations are recorded in the [fixture notes](web-awesome/README.md).

The new performance campaign remeasures frozen En Reve and Fluent WC as controls without changing their artifacts. A larger or smaller tree includes these capability and composition choices. With/without-date counts omit each entire owned field; inaccessible browser picker internals are unavailable, not zero cost.
