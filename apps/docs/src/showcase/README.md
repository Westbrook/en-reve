# Showcase

`/showcase` is a server-rendered creative-collaboration composition, using public `en-*` APIs and native content recipes. Four explicit columns become two and then one. Source and visual order agree; there is no dense/masonry reordering.

- `model.ts`: local fixture records and reset defaults.
- `template.ts`: sixteen named, directly linkable cards and the scope audit.
- `app.ts`: local actions, hydration, theme ownership and file intake.
- `styles.css`: page-owned layout, artwork, and customization through public CSS parts/tokens.
- `presets.ts`: lazy loading of recipes generated by `prepare-docs.mjs` from `tooling/theme-candidates/definitions.json` and its canonical light/dark inputs.

Theme changes use `attachDocumentTheme` without replacing card subtrees. Resetting a card deliberately replaces only that card’s body, keeping its Reset button focused. Theme Reset preserves all fixture values. `en-change` consumption observes or accepts values through the common helpers; no `controlled` or request/commit event pair is introduced.

The file picker and page-wide file drop use `createCandidateFileIntake` and `reopenReviewBundle`. Only validated, compiler-resolved themes reach the document. The importer retains exact-build semantics; older files are rejected without clearing current data. Built-in themes can be downloaded as current-build review bundles, with no fabricated review evidence. Single-mode legacy files disable appearance switching. Reset and disconnect invalidate pending file reads.

The activity display is an application-owned figure and accessible table, not a library chart component. The device tile uses a real link instead of a fake QR code. See `plans/showcase-scope-audit.md` for the bounded list of unbuilt/unplanned families.

Mobile compositions keep Reset actions at the target floor rather than the taller
field-group envelope. Readiness checkboxes share a tight group gap while each label
retains its full touch target. The project field pair responds to its own available
width, and the native date control has a bounded, font-relative width. About this
study opens a named, dismissible popover on tap or keyboard activation. The export
drawer opts into responsive bottom presentation without replacing its controls.

`tests/playwright.showcase-mobile.config.ts` exercises these compositions in
iPhone portrait/landscape, Android phone, and iPad portrait/landscape profiles.
These installed-engine checks complement physical iOS/Android and assistive
technology review; they do not simulate the operating system's picker or keyboard.
