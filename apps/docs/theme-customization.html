03 /

Make registration an explicit decision

The token package supplies a shared property registry. Registration is separate from emitting theme declarations.

Use compatible registration when existing component fallbacks must remain active. Opt into typed registration only when the initial values and interpolation behavior are part of your application’s contract.

  • Full scopes reset public component overrides.
  • Partial scopes emit only the selected tokens.
  • Local CSS remains available for component-specific styling.
  • Typed registration changes what initial and invalid values resolve to; review each property before opting in.
