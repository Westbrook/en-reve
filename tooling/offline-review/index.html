Offline theme review

This package preserves one documentation build and its candidate. All review assets are served from this computer. No package installation or remote service is needed.

  1. Download the packaged candidate, or use candidate.json in the package directory.
  2. Open Theme Review. Under Reopen candidate, choose that file. The application validates and replays the candidate before applying it.
  3. Choose the sticker sheet or a workflow and select Load previews. Compare the baseline and candidate; appearance, density and direction controls remain available.
  4. Export any revised candidate to a separate location. The package stays unchanged; a reload requires reopening your chosen file.
Review is not adoption. A loaded preview does not establish interaction, visual or accessibility acceptance. Record those results separately, retaining the package manifest and candidate. This package does not restore a browser session or submit changes.

The server listens only on 127.0.0.1 and blocks remote resource loading. Links to external documentation still require a connection. Stop the server with Ctrl + C. Run node serve.mjs --verify to check all packaged files.
