Transfer the theme

Download the six baseline variants and shared card Part treatment as CSS, or export the selected typed review draft. Reopen a draft with the same direction, appearance and density selected. Review JSON does not include the separate Part stylesheet.

Scope recipes and limits
Family scopes reach documented members only. There is no input-only radius hook: use a shared control radius or an instance Part. Custom fonts require application font loading. Application portals need an explicit theme boundary at their destination. Color-wheel geometry remains specialized. Vertical writing is not claimed.
CSS export includes baseline variants. A reopened draft is reflected in the live workspace and its JSON export; custom draft edits are not silently folded into the baseline CSS download.
