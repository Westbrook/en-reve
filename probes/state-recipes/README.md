# Packed state and registration consumers

```sh
EN_EXECUTION_OUTPUT=/absolute/new/state-recipes \
  tooling/test-pipeline/with-toolchain.sh npm run test:union -- --pathways=state-recipes
```

The registered pathway builds prerequisites, extracts verified tarballs into an
isolated consumer, compiles against public declarations and rejects workspace
source and elements-package runtime inputs. A split lazy chunk remains a real
browser import. Locked third-party dependencies are the only workspace links.
Each run owns a fresh reserved loopback server; all three pinned engines run with
one worker, no retries and no developer-server reuse.

The [contract](../../packages/primitives/docs/state-consumers.md) and
[receipt](verification-20261002.json) qualify 48 cases, 16 per engine:

- Native query drafts validate text/numeric comparisons and all/any application
  evaluation. Invalid values retain accepted results. Veto and author supersession
  work, and copies cannot mutate accepted clauses by alias.
- Canonical and legacy key extraction remain explicit. Opaque whitespace in a
  valid key is retained; keyed row identity survives reorder/content changes.
  Duplicate/blank keys cannot replace the application records.
- Native range keyboard movement, snapping, fractional limits and minimum gap
  work with EditingController. Tentative FormData is coherent; cancellation and
  silent authoritative normalization preserve both native endpoints.
- Measured overflow delivers each action once, supports native activation,
  recovers focus through collapse/expansion and reconnects at enlarged narrow RTL.
- Actual lazy imports are absent before preparation, which registers nothing.
  Ensure upgrades dependency-first without losing a pre-upgrade edit. Concurrent
  work shares imports; lookup failure starts none. Load failure requires explicit
  retry, while registry conflict preflights dependencies and remains permanent.

Earlier attempts remain in the evidence directory: strict compilation caught an
application method colliding with HTMLElement.matches; a label locator exposed
implicit select labels containing option text; overflow probes inherited an
incorrect width cap; Firefox enlargement exposed an unconstrained fixture text
field. These fixture defects were corrected before the full final matrix passed.
No library runtime changed, and no assertion was omitted to obtain the pass.

Five additional public entries now have named scenarios:45/110 qualified,65
pending. This does not prove every function input or method. Query evaluation,
measurements and focus recovery are application code. Physical IME/AT/touch,
retail Safari/OS, SSR/hydration and separate-owner acceptance remain distinct.
