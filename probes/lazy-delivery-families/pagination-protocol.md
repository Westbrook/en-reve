shared actual-route family campaign. Numeric gates remain those frozen in
`plans/lazy-delivery/family-designs.json`; the candidate selection and native

or incomplete cell remains nonqualifying.

## Browser driver interface and startup

Install the exported, self-contained `installPaginationProbe` through
`context.addInitScript`, passing `{family: 'pagination', policy: arm.policy}`.
It supplies `window.__enFamilyProbe` with the common state, snapshot, arm,
action promise, close, and lifecycle interface, plus `isClosed()`.

Use the shared seven configurations: Chromium, Firefox and WebKit at desktop
1280 by 900 and phone 390 by 844, plus Chromium desktop with CPU 4x, 150 ms
latency, 1.6 Mbps download and 750 Kbps upload. Each configuration has independent
keyboard and pointer cells. Phone pointer means trusted touch; desktop means
mouse. Thirty matched randomized blocks per cell and three arms produce 1,260
pagination timing observations. This matrix extends the existing family
matrix without changing its thresholds. Report median, p75, paired uncertainty,
and sample count; p95 is unavailable below 100 successful observations per cell.

The requested registry is production-default and the observed registry must be
global, matching this actual route. Native scoped qualification belongs to the
separate correctness fixtures. No query parameter relabels this route as scoped.

Startup is observed before scrolling or focus. It requires the real API example
owner to finish hydration, standalone activation and Lit updates, all exact pagers to finish their
updates, fonts to finish loading, every chooser to remain closed, and the fixed
host/record/policy workload to match. The adapter never flushes an update to
create readiness. Recursively connected node counts include the document,
open shadow roots, host nodes, styles, text and comments. Report the selected
primary component and each of the six eligible host denominators separately;
whole-route benefit always uses the complete document, including both controls.
The common acquisition seals the exact Vite HTML/client asset graph, package
archives, selective packed entries, locks, source, harness and engine identities.
HTML is precompressed before browser timing and each sample uses a fresh browser
context. Static route serving and startup do not claim an SSR-render time gate;
no pagination SSR-render timing threshold is invented.

## Native first use, first presentation and repeat

After recording startup and settled traffic, scroll the primary `#api-pagination`
into view. Select its visible native button by the exact accessible name
`Choose a page` (or a single visible `button[popovertarget]`). Responsive desktop
and phone layouts expose the appropriate existing invoker. Call `arm('keyboard')`
and press Enter, or `arm('pointer')` and click/tap. The timestamp is captured in
the trusted Enter keydown or pointer-generated click before the native default
action. The adapter does not prevent a default, manually call showPopover,
replay the gesture, set open state, or await a private preparation API.

One trusted native action must produce exactly one trusted uncanceled click and one
opening beforetoggle. Keyboard Enter must also remain uncanceled; a trusted
keydown followed by a synthetic replayed click cannot qualify. The native shell must be the original startup node.
At the first animation-frame observation where the native popover is visible,
the five-element body must already be complete, the native numeric input must be
focused, enabled, correctly labelled and valid, and its min/max/step/required
contract must match the unchanged pager. Its value must equal the independently declared draft: 1 for first use and 9 for the timed repeat.
The input and Go/Cancel controls must pass real composed hit testing. The panel
must fit the visual viewport and sit above or below its actual invoker. Failure
at that first visible observation fails the attempt rather than extending the
clock until an incomplete presentation repairs itself. The endpoint also
requires the same geometry on consecutive animation frames.

Record first-use data, fill the native page input with `9` outside the timed
interval, and press trusted Escape. Wait for `isClosed()`, which checks native
closure, restored focus on the original invoker, the same input and draft 9. Arm and activate again with
the same input method. The second opening must preserve draft `9`, native input
identity, original shell identity, and every recursively generated body node.
WeakRefs hold identity evidence; no strong diagnostic node array can conceal
retention. The action result includes native opening/click counts, first visible
readiness, endpoint geometry, draft, identity and full census snapshots.

## Retention and evidence limits

Use five fresh Chromium contexts for each arm and lifecycle, giving 30 contexts
for pagination. Run 100 open/close cycles independently for retained-host and
create/open/close/remove lifecycles, with checkpoints at 0, 10, 50 and 100.
The original real route remains intact in both. Disposed instances copy the
primary host's exact public properties and authored child nodes before their
first connection. They have the same page 1 of 12 workload and policy; they do
not replace a route fixture or increase the timed construction workload.

Lifecycle-only actions focus and click the real native invoker, observe the
same complete endpoint, set draft `9` without changing page, dispatch a native
Escape key event to the input, and verify closure, focus restoration, input
identity and the unchanged draft/page. These programmatic actions are retention
evidence, not trusted input latency or human acceptance. Per-cycle listeners use
an AbortController and are removed in finally blocks. Disposed hosts are removed
in finally blocks; the adapter keeps no strong host/input/body references between
cycles and uses no MutationObserver or ResizeObserver.

The shared retention driver records a connected census, JavaScript event listener
count, double-collection heap size, and reported detached DOM diagnostics after
identical settling. Report unsupported detached diagnostics as unavailable,
never zero. CDP's reported detached IDs are a diagnostic subset, not a complete
heap graph or a leak-free claim. Add EN-PAGINATION to that driver's detached-host
classification. The adapter exposes `workload.chooserElements` and
`workload.inputIdentityFailures`, as well as per-host identity and element counts.
From cycle 10 to 100, the frozen gate allows no additional chooser elements or
listeners and requires median post-GC heap growth at most 32 KiB per arm. First
construction is expected and is not measured as repeated-cycle growth.

The frozen remaining gates are: at least 10% fewer recursively connected nodes
on every adopted component; whole-route reduction at least 5% and 32 nodes;
startup median and p75 no greater than eager times 1.05; first-use p75 at most
50 ms and at most eager p75 plus 8 ms; repeat p75 at most eager p75 plus 4 ms.
Construction-only delivery claims zero optional code saving and may not add
requests. Preserve uncertainty, actual n, all errors/aborts, exact cell coverage,
reference/candidate/rollback comparisons and raw receipts. Browser focus and
DOM visibility do not establish spoken assistive-technology behavior or manual
keyboard acceptance; retain those separate review checkpoints.
