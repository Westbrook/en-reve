# Packed native color consumers

The [consumer contract](../../packages/styles/docs/color-consumers.md) covers
independent picker, plane, wheel and channel styles, plus public style barrels
and metadata-driven customization. This fixture imports packed public packages
and owns its native template, state and interactions. It does not import elements
or workspace source aliases.

```sh
EN_EXECUTION_OUTPUT=/absolute/new/run tooling/test-pipeline/with-toolchain.sh npm run test:union -- --pathways=color-recipes
```

Strict declaration compilation and production bundling precede Chromium,
Firefox and WebKit checks, in both CSSResult and portable CSS deliveries.
Scenarios cover independent responsive geometry, native draft validation,
alpha/checker paint, native keyboard and pointer input, capture/clamping/cancel,
RTL coordinates, disabled states, public scoped overrides, export identity,
metadata, narrow/enlarged text and reduced motion.

The first run retains the real portable picker/plane stylesheet collision.
Portable plane users now explicitly adopt color-plane.css in an independent
root. The fixture does not claim arbitrary color parsing, Display-P3 conversion,
calibrated pixels, physical touch, AT speech, retail browsers or SSR/hydration.
