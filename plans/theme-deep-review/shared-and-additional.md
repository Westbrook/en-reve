## Shared architecture: what is solid

- `packages/tokens/src/authoring.ts` accepts finite trusted companion targets and typed, registered public hooks. Arbitrary selectors, raw imported CSS, mechanical properties and type-confused assignments are rejected. Public typography assignments are narrowly allowed.
- `apps/docs/src/theme-review/companion.js` derives companions from current resolved branches, so source edits and managed edits use the same companion values. The document controller and export workflow install the companion after token CSS. Review bundles retain build-bound validation and regenerate CSS.
- Full token themes redeclare semantic inputs and reset registered optional component overrides; partial overrides preserve unrelated inherited pins. Typography, density and explicit component size remain separate. Button motion does not replace semantic selection or immediate keyboard focus.
- Existing source records distinguish source observations from adaptations. `plans/theme-inspired-adoption.md` supersedes older claims that tracking, layered card shadows, press motion and family timing are unavailable. Those earlier limitations must not be copied into a new verdict.

These are appropriate foundations for a richer interpretation. Expanding them should preserve the existing pure import, event, SSR, native editing and protected target contracts.
