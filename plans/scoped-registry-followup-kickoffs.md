These are independent tasks for use **after the validated branch is merged into local `main`**. They are not remaining phases of the sealed Phase 1–6 plan. Each fenced block can be copied into a new task without the surrounding document. The task verifies its starting commit; it must not assume that a later task already exists or has landed.

The parent merge task owns current-plan documentation, integration-check alignment and any required regression repair, including the number-input CSS specificity issue found during validation. The numbers below identify independent follow-up tasks, **not new numbered phases** of the adoption plan.
