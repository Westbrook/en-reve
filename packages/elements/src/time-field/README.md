# en-time-field

Localized local wall-time entry composed with `en-date-picker`. Import `@en-reve/elements/define/time-field.js`. No timezone conversion or scheduling policy is implied.

`value`, `min` and `max` use canonical ASCII `HH:mm` (or `HH:mm:ss` with `precision="second"`). The default precision is `minute` and `step` is 60 seconds. Minute precision needs a step divisible by 60. Seconds are whole integers; offsets, Z, fractional seconds, 24:00 and leap seconds are invalid. Invalid author values remain inspectable but invalid and omitted from FormData.

`locale="en-US"` is explicit and deterministic by default. `hour-cycle="auto|12|24"` controls display; auto follows the locale with midnight normalized to 12 AM or 00:00. Localized digits, separators and AM/PM markers round-trip. Canonical 24-hour text is also accepted. Translated `label`, `description`, `format-label`, `invalid-label`, `configuration-label` and application `error` can be supplied. Built-in constraint messages are English. Locale/format changes never change the accepted value; an existing draft is parsed in the format in which editing began.

Typing emits raw localized `en-input` drafts. Blur or Enter commits valid text through one cancelable `en-change` carrying canonical previous/proposed values. Veto restores accepted display and form data; explicit author writes win. Escape or `cancelEdit()` restores the accepted value. Invalid drafts remain visible and block submission; they never silently round. `commit()` accepts a valid draft. A form requested programmatically during editing requires `commit()` first. Invalid/uncommitted drafts are omitted from FormData; accepted form state is retained for restoration.

Arrow Up/Down adjusts the segment at the caret: whole hours, minutes, seconds, or an AM/PM toggle. Numeric movement uses the smallest whole segment increment compatible with `step` (for example, minutes advance by 15 for step=900); smaller units are retained. Carry is allowed across units, and crossing midnight requires `wrap`. Separators target the preceding segment; selections use their start offset. The adjusted segment stays selected for repeated key presses, including localized digits and prefix day periods. Bounds, step validation, veto, readonly and composition still apply. `stepUp()`/`stepDown()` remains a whole-value operation using one configured step. Steps are anchored to min, otherwise 00:00. Bounds are inclusive. `wrap` explicitly permits reversed min/max as an overnight interval, and stepping across midnight; it does not imply a date change. Stepping stops at a forbidden boundary. Disabled and disabled-fieldset values are omitted; readonly values submit and remain focusable. Required, reset, restoration, size, label/description slots and field/focus Parts follow the shared field contract.

Submit dates and times in separate named fields. The consuming application validates date-time ordering, chooses an IANA timezone, and resolves missing/repeated daylight-saving times. Use the same locale/Intl capabilities on the server and client; early native edits are preserved at hydration. Manual screen-reader, IME and physical mobile qualification remains separate from automated browser coverage.
